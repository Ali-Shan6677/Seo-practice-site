BRIGHTPATH PLUMBING — FREE SEO PRACTICE SITE

The site is fictional and for learning only.

DEPLOY FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a PUBLIC repository named seo-practice-website.
3. Upload every file in this folder to the repository root.
4. Open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch main and folder /(root), then Save.
7. After publishing, the URL format will be:
   https://YOUR-GITHUB-USERNAME.github.io/seo-practice-website/

Replace YOUR-USERNAME in the canonical links, sitemap.xml, and robots.txt with your actual GitHub username and published base URL.

GOOGLE SEARCH CONSOLE
1. Open https://search.google.com/search-console/
2. Add a URL-prefix property using your actual live website URL.
3. Follow the ownership verification instructions. If Google provides an HTML verification file, download it and upload it to the repository root using the exact filename.
4. Open Sitemaps and submit sitemap.xml.
5. Use URL Inspection to check each page.
6. Search performance and indexing reports may take time to appear.

This is a static website; the contact page does not submit messages. No real business is represented.
